# InterviewMate - Feature Specification

## Core USP
InterviewMate is an adaptive placement journey for students/freshers.

## Flow
1. Create profile
2. Upload resume
3. Upload target job description
4. Extract skills
5. Calculate job match
6. Detect skill gaps
7. Take diagnostic
8. Generate roadmap
9. Practice each placement round
10. Run full placement simulation
11. Track performance
12. Get readiness recommendation

## Rounds
- Aptitude
- Coding
- Technical
- Project
- Managerial
- HR / Communication

## AI Mock Interview
- Two-way voice interviewer with browser speech recognition and spoken AI questions
- Automatically submits spoken answers after 5 seconds of silence
- Complete campus-placement coverage: aptitude, reasoning, technical, coding, project, critical thinking, managerial, communication, HR, workplace judgement and ethics
- Offline rule-based or optional Claude-powered follow-ups and final feedback report
- Attempts and recognized-text transcripts are stored in SQLite; microphone audio is not recorded
